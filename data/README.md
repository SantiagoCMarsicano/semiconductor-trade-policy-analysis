# Data

## raw/

Original source files. Do not manually modify source data after download.

Expected initial sources:
- WSTS / SIA regional semiconductor sales
- China-specific WSTS/SIA series where available
- Policy chronology source files if stored locally

## processed/

Cleaned and harmonized datasets generated by the R workflow.

Planned master fields include:
- date
- world
- china
- asia_pacific_other
- americas
- europe
- japan
- policy_period

Derived variables should be generated reproducibly in code rather than edited manually.
